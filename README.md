# Digital Xperts Popup

Wtyczka WordPress: popup i pasek informacyjny dla odwiedzających strony. Opis funkcji jest w `readme.txt`, instrukcja dla agentów w `AGENTS.md`.

Popup pochodzi z Menedżera Strony AI 2.8.0 i korzysta z tych samych ustawień (`asm_popup`, `asm_popup_library`). Pasek zapisuje się w opcji `dxp_bar`.

Instalacja: paczka `digital-xperts-popup-X.Y.Z.zip` z wydań. Konektor Menedżera Strony AI (2.9.0+) instaluje ją operacją `plugin.install` ze sluga `digital-xperts-popup`.
